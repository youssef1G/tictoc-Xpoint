# Tic Toc Xpoint

A full-stack e-commerce platform.

## Tech Stack
- **Frontend:** React 18 + Vite + Tailwind CSS
- **Backend:** Node.js + Express (ESM)
- **Database:** Supabase (PostgreSQL)
- **Image hosting:** Cloudinary

## Running Locally

### Backend
```bash
cd backend
npm install
cp .env.example .env
# Fill in your .env values
node server.js
```

### Frontend
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

## Admin Access
Go to `/admin-access` — not linked anywhere on the storefront.
